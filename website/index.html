FAQ

Perguntas frequentes

Meus dados de saúde ficam seguros?

Sim. O Nouri é compatível com a LGPD. Seus registros são cifrados com AES-256 antes de serem armazenados. Nenhum dado é vendido ou compartilhado com terceiros. Você pode solicitar exclusão completa a qualquer momento.

Funciona só pelo Telegram?

Por enquanto, o bot funciona pelo Telegram. O painel web é acessível por qualquer navegador para ver seu histórico, gerar relatórios PDF e gerenciar sua conta.

Qual a precisão no reconhecimento de alimentos?

Nossa base prioritária é a TACO/UNICAMP (306 alimentos) complementada pela TBCA/USP-FoRC (1.994 itens). Para fotos, mais de 75% de acerto. Para texto, mais de 80% nos 500 alimentos mais comuns. Itens não encontrados são estimados pela IA com aviso explícito.

Posso cancelar quando quiser?

Sim, sem multa e sem complicação. Você cancela pelo painel web ou pelo próprio bot no Telegram. O plano fica ativo até o fim do período já pago.

O plano Nutricionista serve para clínicas?

Sim. Um nutricionista cadastrado convida pacientes via link direto no Telegram. Você tem acesso ao histórico, gráfico de calorias em 30 dias, notas clínicas e PDF por paciente — tudo em um único painel.

E se meu alimento não estiver no banco de dados?

O Nouri usa um pipeline de 5 camadas: cache → TACO → TBCA → USDA → estimativa via IA. Se nenhum banco tiver o alimento, o Claude estima com base em similares e avisa que é uma estimativa.
